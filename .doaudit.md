# Opakovaný komplexný audit pre NephroSite (nephrosite.polascin.net)

## Cieľ

Vykonaj opakované behy hĺbkového komplexného auditu webovej aplikácie **nephrosite.polascin.net** podľa [`.audit.md`](.audit.md) (bezpečnostný audit OWASP, HTTP hlavičky, noindex pravidlá, syntaktická správnosť PHP/HTML/CSS/JS kódu, SEO, responzívny dizajn, prístupnosť WCAG 2.1 AA, GDPR, cookie banner, medicínsky disclaimer, archívny oznam a jazyková korektúra slovenčiny a medicínskej terminológie) a dodržiavaj bezpečnostné pravidlá uvedené v `.audit.md`.

## Postup

1. Spusti audit podľa kontrolného zoznamu v [`.audit.md`](.audit.md).
2. Zaznamenaj všetky nálezy vrátane ich závažnosti, príčiny a odporúčanej opravy.
3. Implementuj opravy a vylepšenia nájdené v aktuálnom kole.
4. Over zmeny relevantnými projektovými kontrolami:
   - PHP syntax lint: `php -l <file.php>` pre všetky zmenené PHP súbory
   - Kontrola kvality PHP: `.\tools\quality.ps1` (PHPStan + PHP-CS-Fixer)
   - Statická kontrola HTML/CSS/JS
   - Smoke check živých URL: `curl -sIL https://nephrosite.polascin.net/`
   - Overenie funkčnosti automatického deployu cez GitHub Actions workflow
5. Zapíš výsledky, vyriešené nálezy a poznatky pre ďalšie behy do [`.audit.md`](.audit.md) ako nový „Beh #X" s odvolávkami na opravené súbory.
6. Opakuj kroky 1 až 5, kým audit nebude nachádzať žiadne nové bezpečne opraviteľné chyby alebo bugy.

## Bezpečnostné pravidlá

- Nevykonávaj nebezpečné alebo neoverené automatické opravy.
- **ZÁKAZ modifikácie Git LFS súborov** (`docs/nephrogame.gif` a iné binárne súbory v `docs/`).
- Pri bezpečnostných nálezoch uprednostni obranné riešenia a minimalizuj riziko regresie (prepared statements, XSS escapovanie, CSP hlavičky, HTTPS enforcement).

## Dokončenie (povinné vždy)

Po úspešnom ukončení všetkých auditných kôl **vždy** vykonaj nasledujúce kroky – bez výnimky, aj keď boli zmeny medzičasom čiastočne nasadené lokálnym hookom:

1. Skontroluj finálny diff a stav repozitára (`git status`, `git diff --stat`).
2. Uisti sa, že všetky PHP súbory prechádzajú `php -l` a že kód je správne zformátovaný (`.\tools\quality.ps1`).
3. **Commitni všetky relevantné zmeny** (vrátane aktualizácií `.audit.md` a tohto `.doaudit.md`, ak boli upravené) s výstižnou správou. Nekommituj `.cursor/`, secrets ani Git LFS binárne súbory.
4. **Pushni na hlavnú vetvu `master`** (`git push -u origin HEAD` / `git push origin master`). Repozitár používa `master` ako default branch (ekvivalent „main“).
5. **Over CI/CD deploy:**
   - Počkaj na úspech GitHub Actions workflow `Deploy to nephrosite.polascin.net` (`gh run list` / `gh run watch`).
   - Over produkciu: `curl -sIL https://nephrosite.polascin.net/` (HTTP 200, bezpečnostné hlavičky).
   - Spot-check aspoň jednej zmenenej stránky alebo textu, aby bolo jasné, že nový commit je naživo.
6. Do posledného „Beh #X“ v [`.audit.md`](.audit.md) **zapíš** hash/commit, výsledok pushu, stav GitHub Actions a výsledok produkčného smoke checku.

Audit sa považuje za dokončený až po úspešnom **commite + pushi na `master` + overenom deployi**.
