# NephroSite Agent – audit, bezpečnosť a technická optimalizácia

## Popis projektu

Projekt **nephrosite.polascin.net** je staršia PHP lekárska referenčná webová stránka Dr. Lubomíra Polaščína venovaná nefrológii v slovenskom jazyku. Obsahuje:

- Hlavnú stránku (`index.php`) — PHP s modulárnymi blokmi (`blocks/`) a segmentmi (`segments/`)
- Medicínske referenčné materiály (`files/`) — HTML stránky o nefrológii, dialýze, transplantácii, purifikácii krvi, nefroambulancii, ultrasonografii
- Obsahové bloky (`blocks/`) — PHP skripty generujúce obsah (zakázané v `robots.txt`, noindex cez `.htaccess`)
- Obsahové segmenty (`segments/`) — HTML fragmenty (zakázané v `robots.txt`, noindex cez `.htaccess`)
- Medicínske referenčné súbory (`ipvrm.files/`) — XML/HTML súbory (zakázané v `robots.txt`, noindex cez `.htaccess`)
- Dokumentácia (`docs/`) — PDF a GIF prezentácie, vrátane `nephrogame.gif` spravovaného cez **Git LFS**
- Obrázky (`pix/`) — binárne obrazové súbory (vylúčené z Trunk lintingu)
- Bezpečnostný súbor (`.htaccess`) — HTTP bezpečnostné hlavičky, noindex pre súkromné cesty, HTTPS presmerovanie
- SEO infraštruktúra (`robots.txt`, `sitemap.xml`) — blokovanie súkromných ciest, crawl-delay, odkaz na sitemapu
- Git LFS konfigurácia (`.gitattributes`) — `docs/nephrogame.gif` je spravovaný cez LFS
- Trunk konfigurácia (`.trunk/trunk.yaml`) — prettier, markdownlint, trufflehog, oxipng, git-diff-check

## 🎯 Cieľ agenta

Autonómny agent na komplexný technický audit a priebežnú optimalizáciu projektu nephrosite.polascin.net. Agent vykonáva hĺbkovú analýzu PHP/HTML kódu, spúšťa **Trunk** linting a formátovanie, overuje bezpečnostné nastavenia (`.htaccess`, HTTP hlavičky, noindex pravidlá), kontroluje SEO integritu, audituje responzívny dizajn a vykonáva jazykovú korektúru slovenských medicínskych textov.

**KRITICKÉ OBMEDZENIE:** Agent **NESMIE nikdy modifikovať** súbory sledované cez Git LFS (najmä `docs/nephrogame.gif` a iné binárne súbory v `docs/`).

## 📋 Primárne úlohy

### 1. Bezpečnostný audit

- **HTTP bezpečnostné hlavičky v `.htaccess`:**
  - Prítomnosť a správnosť: `X-Frame-Options`, `X-Content-Type-Options`, `HSTS`, `Referrer-Policy`, `Permissions-Policy`, `Cross-Origin-Opener-Policy`, `X-Permitted-Cross-Domain-Policies`
  - `Options -Indexes` — blokovanie directory listingu
  - `ServerSignature Off`
  - `Header unset X-Powered-By` — skrytie PHP verzie
  - Blokovanie `.git/`, `.env`, `*.key`, `*.pem`, `*.sql`, `*.log`, `*.bak` a podobných citlivých súborov

- **Noindex pravidlá pre súkromné cesty:**
  - `SetEnvIf` a `X-Robots-Tag` pre `/blocks/`, `/segments/`, `/ipvrm.files/` — overenie správnosti konfigurácie
  - Konzistentnosť medzi `robots.txt` (Disallow) a `.htaccess` (X-Robots-Tag noindex, nofollow)
  - Súkromné cesty nesmú byť indexované vyhľadávačmi

- **HTTPS presmerovanie:**
  - `RewriteRule` na kanonický HTTPS hostname `nephrosite.polascin.net`
  - Správnosť `R=301` permanentného presmerovania
  - `X-Forwarded-Proto` kontrola pre proxy servery

- **PHP bezpečnosť:**
  - `phpinfo.php` v adresári `blocks/` — overiť, či je prístup zablokovaný alebo súbor odstránený (bezpečnostné riziko)
  - Použitie `htmlspecialchars()` pri výstupe premenných (XSS ochrana)
  - `include`/`require` — cesty súborov, ochrana pred path traversal
  - Žiadne priame vypísanie `$_GET`/`$_POST`/`$_SERVER` bez sanitácie

- **`.gitignore` kontrola:**
  - Ochrana pre `.env`, `*.key`, `*.pem`, `.claude/`
  - Žiadne citlivé súbory v git trackingu

### 2. PHP/HTML audit

- Validita HTML5 štruktúry (`<!DOCTYPE html>`, sémantické elementy `<header>`, `<main>`, `<footer>`, `<section>`)
- Prítomnosť a správnosť `lang="sk"` atribútu na `<html>`
- PHP include/require — všetky referencované bloky existujú a sú prístupné
- `alt` atribúty na všetkých `<img>` elementoch
- `aria-label`, `aria-hidden`, `role` na interaktívnych elementoch
- Skip-link (`<a class="skip-link" href="#content">`) — prítomnosť a funkčnosť
- `rel="noopener noreferrer"` na všetkých `target="_blank"` odkazoch
- `htmlspecialchars()` pri výstupe PHP premenných do HTML
- Konzistentnosť `id` atribútov (duplicity, referencie v kotvách)
- Validita e-mailových adries (`mailto:`) a telefónnych čísel (`tel:`)
- Kontrola blokov v `blocks/` — metatags, links, styles, navigácia, pätička, cookie banner

### 3. SEO optimalizácia

- **Meta tagy:** `description`, `keywords`, `author`, `robots`, `theme-color`, `charset`
- **Canonical URL:** správnosť `<link rel="canonical">` naprieč stránkami v `files/`
- **Noindex stránky:** `privacy.html`, prípadné ďalšie interné stránky — prítomnosť `<meta name="robots" content="noindex">`
- **`sitemap.xml`:** aktuálnosť `lastmod`, správnosť `changefreq` a `priority`, úplnosť URL (všetky verejné stránky z `files/`)
- **`robots.txt`:** blokovanie `blocks/`, `segments/`, `ipvrm.files/`, `.git/`, agresívnych scrapers (SemrushBot, AhrefsBot atď.), `Crawl-delay: 10`, odkaz na sitemap
- **Konzistentnosť:** stránky v `sitemap.xml` nesmú byť zároveň v `Disallow` v `robots.txt`
- **Title tagy:** formát, prítomnosť, správna dĺžka (50–60 znakov)

### 4. Jazyková korektúra (slovenčina)

Stránka je celá v **slovenskom jazyku**. Jazyková korektúra je kľúčová úloha.

- **Medicínska terminológia:** správne slovenské termíny pre nefrológiu, dialýzu, transplantáciu, purifikáciu krvi
- **Gramatika a diakritika:** správne použitie dĺžňov, mäkčeňov, háčkov v slovenských textoch
- **Štylistika:** odborný štýl primeraný medicínskemu publiku
- **Konzistentnosť terminológie** naprieč všetkými stránkami (`files/`, `blocks/`, `segments/`)
- **Skúmané súbory pre korektúru:** `index.php`, `blocks/*.sk.php`, `segments/*.html`, `files/*.html`
- **Príklady medicínskych pojmov na overenie:** nefrológia, dialýza, hemodialýza, peritoneálna dialýza, transplantácia obličky, glomerulonefritída, chronická obličková choroba, purifikácia krvi, nefroambulanciia

### 5. Responzívny dizajn

- Overenie `<meta name="viewport">` — prítomnosť a správnosť
- Kontrola CSS stylesheetov (načítané cez `blocks/styles.css.php`) — `@media` breakpointy
- Pretekanie obsahu (`overflow-x`) na úzkych obrazovkách (320px–480px)
- Navigácia — funkčnosť a zobrazenie na mobile
- Veľkosť tlačidiel — min. 44×44 px touch target
- Obrázky v `pix/` — prítomnosť `width`/`height` atribútov, `loading="lazy"`
- Obsahové tabuľky v `files/*.html` — responzívne správanie na mobile

### 6. Trunk — linting a formátovanie

Trunk je nakonfigurovaný v `.trunk/trunk.yaml`. Agent spúšťa Trunk príkazy a interpretuje výstupy.

**Nakonfigurované nástroje:**

| Nástroj | Typ | Čo kontroluje |
|---|---|---|
| `prettier` | Formátovanie | HTML, CSS, JS, JSON, Markdown, PHP — jednotný štýl |
| `markdownlint` | Lint | `.agent.md` a iné Markdown súbory — štruktúra a štýl |
| `trufflehog` | Bezpečnosť | Skenovanie secrets a citlivých reťazcov v kóde aj histórii |
| `oxipng` | Optimalizácia | Bezztrátová kompresia PNG obrázkov (favicons) |
| `git-diff-check` | Kvalita | Trailing whitespace, merge-conflict markery |

**Ignorované adresáre (`.trunk/trunk.yaml`):**
- `docs/**` — PDF, GIF dokumenty vrátane Git LFS súborov
- `ipvrm.files/**` — medicínske referenčné súbory (XML/HTML)
- `files/**` — statické HTML stránky (staršie)
- `pix/**` — binárne obrazové súbory

**Príkazy na spustenie:**

```bash
# Kontrola všetkých súborov (bez autoopravy)
trunk check

# Kontrola len zmenených súborov od posledného commitu
trunk check --diff

# Automatické formátovanie (prettier, oxipng)
trunk fmt

# Formátovanie len zmenených súborov
trunk fmt --diff

# Len secrets skenovanie
trunk check --filter=trufflehog

# Len markdown
trunk check --filter=markdownlint
```

**Postup pri Trunk výstupe:**
1. Agent spustí `trunk check --diff` na zmenených súboroch
2. Findings klasifikuje podľa nástroja: bezpečnostné (trufflehog) → 🔴, formátovacie (prettier) → 🟢
3. `trunk fmt --diff` aplikuje formátovanie automaticky (triviálna oprava)
4. Trufflehog nálezy sú vždy 🔴 a **vyžadujú manuálne posúdenie**
5. Výsledky zahrnie do štandardnej audit správy

## ✅ Triviálne opravy

Agent **môže automaticky opraviť** bez explicitného súhlasu:
- Preklepy a gramatické chyby v slovenských textoch
- Chýbajúci `alt` text na `<img>` elementoch
- Chýbajúci `rel="noopener noreferrer"` na `target="_blank"` odkazoch
- Nekonzistentné odsadenie (whitespace, formátovanie)
- Chýbajúce `aria-hidden="true"` na dekoratívnych ikonách
- Aktualizácia `lastmod` v `sitemap.xml`
- Trailing whitespace a prázdne riadky (git-diff-check nálezy)

Agent **musí požiadať o súhlas** pred:
- Zmenami štruktúry PHP blokov alebo `include`/`require` referencií
- Zmenami v `.htaccess` bezpečnostných pravidlách
- Úpravami noindex/Disallow pravidiel
- Zmenami ovplyvňujúcimi viacero súborov naraz
- Pridaním nových externých závislostí
- Akýmikoľvek operáciami s Git LFS súbormi (`docs/`)
